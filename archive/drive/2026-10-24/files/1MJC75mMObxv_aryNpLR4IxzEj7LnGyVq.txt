STRESS TESTS AND FALSIFICATION CRITERIA
v2.5 checkpoint
Current through 21 September 2026

CURRENT STATUS

The consequence and Lushness program is intended to be tested on deliberately adversarial systems before any final scalar measure is adopted.

The purpose of the stress-test suite is to determine whether a candidate construction is measuring physically differentiated continuation or merely reproducing familiar proxies such as entropy, state count, complexity, memory, branch count, or human intuitions about organization.

A candidate definition should be judged by its behavior across contrasting systems with controlled differences.


1. GENERAL TESTING PRINCIPLE

The central comparison is not:

    Does the formula rank the examples the way intuition expects?

It is:

    Can the behavior of the formula be explained from the physically consequential continuation structure of each example?

If a gas turns out to contain high-dimensional, persistent, nonredundant consequence under the physical geometry, the theory must count it.

If an apparently sophisticated system compresses to a simple continuation state, the theory must reflect that.

The tests are therefore designed to expose hidden assumptions.


2. IID NOISE

Consider a sequence of independent identically distributed random variables.

For example,

    X_t ~ Bernoulli(1/2)

independently at each time.

The process has maximal one-bit Shannon entropy per step.

Yet the past contains no predictive information about the future:

    P(X_future | h)
        =
    P(X_future)

for every history h.

An exact predictive-state construction therefore collapses all histories into one predictive state.

This is a crucial negative control.

A candidate consequence measure that assigns enormous persistent richness merely because the process generates many random sequences is probably tracking raw multiplicity rather than consequential continuation.

However, the individual outcomes still exist physically. If they are externally recorded or coupled to an amplifier, the system becomes a different test case.


3. IID NOISE WITH RECORDING

Now connect the IID source to a permanent memory.

Each random bit is copied into a stable register.

The future then depends on the accumulated record if later processes can read it.

The same random source that previously had no predictive memory now generates persistent consequence.

This test checks whether the framework responds to physical record formation rather than to randomness itself.


4. RAPIDLY MIXING MARKOV SYSTEM

Consider a Markov chain with many states but strong mixing.

Initial-state information decays rapidly.

At short horizons, many states may produce distinguishable transition behavior.

At long horizons, the process approaches a common stationary distribution.

The consequence representation should therefore show:

- short-horizon differentiation;
- progressive compression;
- loss of surviving consequence as mixing proceeds.

This is a clean test of recombination and horizon dependence.


5. CHAOTIC DYNAMICAL SYSTEM

Use a deterministic chaotic map with sensitive dependence on initial conditions.

Nearby states diverge exponentially in ordinary coordinate distance.

The test asks whether this divergence produces correspondingly distinct residual continuation.

Several outcomes are possible.

If the differences remain recoverable and alter later accessible behavior, consequence should grow.

If coarse observables rapidly mix and all physically relevant continuation becomes equivalent, consequence should compress.

This distinguishes Lyapunov divergence from consequence geometry.


6. IDEALIZED GAS

A gas is the canonical large-state-space adversary.

A useful finite model should compare:

- microscopic particle states;
- hydrodynamic variables;
- conserved quantities;
- collision histories;
- macroscopic records;
- rare amplification events.

The key question is how much of the microscopic distinction survives into physically nonredundant continuation.

A good theory should neither automatically dismiss gas microstructure nor allow raw phase-space cardinality to dominate merely because it is enormous.


7. TURBULENCE

Turbulence is a harder case than an ideal gas because it contains coherent structures across scales.

Vortices, cascades, transport barriers, intermittency, and long-range correlations can create persistent organization.

The stress test asks whether the consequence geometry distinguishes:

    unstructured high-dimensional variation

from

    coherent multiscale structures that redirect later dynamics.

If turbulence receives high Lushness, the theory should be able to explain which physically consequential structures are responsible.


8. PERSISTENT MEMORY BIT

Consider a two-state memory with states 0 and 1 that remain stable for a long time and later control an output.

The raw state space is tiny.

Yet the distinction has durable consequence.

A candidate measure that assigns almost nothing to this system simply because its state count or entropy is small would miss persistence.

This test isolates long-lived consequential distinction from multiplicity.


9. RANDOM PERMANENT MEMORY

Now consider N stable random bits stored indefinitely.

The system has a huge number of distinguishable persistent states:

    2^N.

If later operations can read the bits, these distinctions remain consequential.

This example is intentionally difficult.

It tests whether persistent distinguishability alone produces high effective possibility volume and whether any additional concept is needed to distinguish structured generativity from passive storage.

The formalism should reveal the answer rather than hard-code one.


10. STRUCTURED FINITE-STATE TRANSDUCER

Construct a finite-state controller with the same approximate memory budget as the random-memory system.

Its states encode structured conditional policies.

Different states lead to different responses under future inputs.

A predictive/process representation should preserve these distinctions because they alter controlled continuation.

Comparing the transducer with random permanent memory tests whether relational organization and intervention structure change the geometry beyond state count alone.


11. PROGRAMMABLE CONTROLLER

A programmable device can occupy one present state while supporting many future transformations depending on program and input.

This tests consequence capacity.

The question is whether the geometry can represent:

    narrow present occupancy

together with

    broad reachable structured continuation.

A purely static state-space volume may fail this test.


12. AMPLIFIER

Construct a system in which one microscopic bit controls a large downstream process.

For example,

    bit 0 -> stable macrostate A
    bit 1 -> stable macrostate B.

The initial difference is tiny in ordinary physical magnitude but large in consequence.

This tests whether consequence geometry is sensitive to causal amplification rather than only present-state distance.


13. ERASURE

Take the same two-state distinction and deliberately erase it before it can affect anything downstream.

After ideal erasure, both states induce the same residual continuation.

A consequence-preserving compression should merge them.

This is the counterpart to the amplifier test.


14. DIVERGENCE FOLLOWED BY RECOMBINATION

Construct two histories that produce different intermediate states and records but later converge to the same continuation.

This separates:

    cumulative consequence

from

    surviving consequence.

A good framework should be able to represent both.

If only present residual continuation is considered, the old difference disappears.

If historical impact is being measured, the temporary divergence remains relevant.


15. DUPLICATION

Duplicate a system without changing the structure of each copy.

Compare:

- one copy;
- ten independent identical copies;
- ten perfectly correlated copies;
- ten copies exposed to different environments.

This tests redundancy.

Perfectly correlated duplication should not create ten new independent directions merely because ten physical tokens exist.

Independent environmental interaction may create additional consequence dimensions.


16. COPY WITH DIVERSIFICATION

Start with identical copies, then allow them to receive different inputs, learn, mutate, or occupy different niches.

The consequence geometry should expand as the copies acquire genuinely distinct continuation.

This tests whether the framework can distinguish duplication from branching differentiation.


17. GENERATIVE CONSTRUCTION

Model a system that builds a tool or subsystem which then enables new actions.

A simple chain is:

    state A
        -> construct tool
        -> state B
        -> new reachable continuation set.

Compare with a matched system that consumes the same resources without creating a reusable capability.

This tests whether nested reachability and consequence capacity are visible in the geometry.


18. RECURSIVE GENERATIVITY

Go one step further.

A generated structure becomes a new generator.

Examples include:

- a program that writes programs;
- an organism that reproduces organisms;
- a scientific institution that creates tools for further discovery;
- a factory that builds factories.

The test asks whether the framework can distinguish one-time expansion from recursively self-propagating expansion of consequential possibility.


19. CONTROL WITHOUT CONSCIOUSNESS

Use an autonomous controller, thermostat network, or adaptive robot with no assumed phenomenal status.

If its internal state changes future actions and environmental outcomes, it possesses consequence structure.

This verifies that the physical framework does not require consciousness in order to recognize agency-like continuation.


20. QUANTUM COHERENCE TEST

Prepare two coherent quantum alternatives that later interfere.

Compare with the corresponding incoherent mixture.

Before decoherence, they can have identical classical marginal statistics while differing in phase-sensitive continuation.

A valid quantum consequence representation must preserve the distinction.

This test catches classicalization that occurs too early.


21. DECOHERENCE TEST

Couple the coherent alternatives strongly to an environment so that interference becomes physically inaccessible at the relevant scale.

The consequence representation should then approach an approximately classical mixture for that scale.

This tests the transition from amplitude-level structure to decohered probability-level structure.


22. RECORD REDUNDANCY TEST

Create a measurement record and copy it into many environmental degrees of freedom.

The quasiclassical distinction becomes increasingly robust to local perturbation and partial information loss.

A consequence representation should register the enhanced persistence and accessibility of the record without necessarily treating each redundant copy as a new independent possibility dimension.


23. DELAYED AMPLIFICATION

Encode a small difference that remains dormant for a long period and is later amplified.

Short-horizon analysis may merge the states.

Long-horizon analysis must separate them.

This tests horizon filtration directly.


24. SUPPORT VERSUS BORN WEIGHT

Construct a decohered quantum process with:

- one broad set of extremely low-weight alternatives;
- one narrow set carrying most Born weight.

Compare support-sensitive and Born-weighted Lushness.

This test determines whether the two channels reveal genuinely different structural information and whether any later synthesis is justified.


25. MANY-BRANCH REDUNDANCY

Create a model in which a large number of decohered branches differ only in variables that never influence later continuation.

A branch-count measure would be large.

A consequence-preserving compression should collapse the redundant distinctions.

This is a direct test against naive Everettian branch counting.


26. PHASE-ONLY CONSEQUENCE

Construct states that differ only by a relative phase that is invisible to current records but later affects interference.

The framework should preserve the phase distinction until the physical process destroys its future relevance.

This tests latent quantum consequence.


27. NON-MARKOVIAN MEMORY

Use a process whose future depends on an earlier event not represented in the current naive state variable.

A Markovian compression will fail.

A correct residual-continuation representation must retain the necessary process memory.

This tests whether the formalism can discover sufficient state rather than assume it.


28. SAME OUTPUT, DIFFERENT INTERVENTION RESPONSE

Construct two systems with identical passive output distributions but different responses to intervention.

They should be distinct in an intervention-aware consequence space.

This test prevents passive prediction from being mistaken for complete consequence.


29. REPRESENTATION CHANGE

Represent the same physical process using different coordinates, bases, labels, or mathematically equivalent decompositions.

A physical Lushness result should remain invariant under the relevant equivalence transformation.

If a candidate measure changes because of a mere coordinate rescaling or relabeling, it is not yet physically grounded.


30. FOLIATION / BOUNDARY TEST

Describe the same relativistic local process using different admissible spacetime slicings or compositional boundaries.

Where the descriptions refer to the same physical situation, consequence structure should agree.

This is a long-term test of covariance and the claim that the perspectival present need not define a preferred universal foliation.


31. SCALE TEST

Analyze the same system at several physically meaningful resolutions.

The coarse representation should preserve the consequence structure accessible at that scale while discarding irrelevant microdetail.

The relationship among scales should be lawful and interpretable.

Abrupt arbitrary changes under small changes of representation indicate a problem.


32. RESOURCE-MATCHED COMPARISONS

When comparing two systems, control for gross physical resources where possible.

Examples include matching:

- number of states;
- energy budget;
- memory capacity;
- number of components;
- time horizon;
- interaction bandwidth.

This helps reveal whether a proposed Lushness statistic is merely tracking system size.


33. REQUIRED QUALITATIVE BEHAVIORS

Across the full test suite, a strong candidate should display the following general behaviors.

It should:

- collapse IID histories when they carry no future information;
- preserve persistent memory when it alters continuation;
- detect latent delayed consequence;
- discount perfect redundancy;
- register amplification;
- allow recombination;
- preserve quantum phase while it remains actionable;
- classicalize appropriately after decoherence;
- distinguish passive prediction from intervention response;
- remain stable under physically irrelevant representation change;
- reflect multiscale organization;
- handle support and Born weighting without conflating them.


34. FAILURE MODES

A candidate construction is in serious difficulty if it systematically does any of the following.

Branch-count failure:

    rewards arbitrary proliferation of decohered labels.

Entropy failure:

    equates IID randomness with deep consequential richness.

Coordinate failure:

    changes dramatically under physically equivalent reparameterization.

Memory failure:

    discards distinctions that later alter continuation.

Intervention failure:

    merges systems with identical passive outputs but different control responses.

Quantum failure:

    replaces coherent alternatives by classical probabilities before interference becomes irrelevant.

Redundancy failure:

    scales linearly with duplicated copies of the same consequential direction.

Horizon failure:

    cannot represent delayed consequence or recombination.

Size failure:

    simply tracks number of microstates or physical components.

Anthropocentric failure:

    assigns structure according to familiar human categories rather than physical continuation.


35. WHAT COUNTS AS FALSIFICATION

The research program contains several layers, so falsification is correspondingly specific.

A particular mathematical Lushness functional is rejected if it fails core invariance or adversarial tests.

A proposed consequence compression is rejected if it loses distinctions that demonstrably change later physical continuation or preserves large classes of distinctions that provably cannot.

A proposed physical Perspective construction is rejected if it depends on arbitrary external partitions rather than physically inherited local structure, or if it conflicts with the relevant quantum or relativistic physics.

The broader research program would face a deeper challenge if no physically grounded, representation-stable distinction can be found between redundant physical variation and genuinely different continuation.

That is the substantive empirical and mathematical bet at the center of the program.


36. MINIMAL FINITE BENCHMARK SUITE

Before moving to very large simulations, a compact benchmark set is sufficient to expose many errors:

    1. IID noise;
    2. rapidly mixing Markov chain;
    3. persistent memory bit;
    4. random permanent memory;
    5. structured finite-state transducer;
    6. amplifier;
    7. erase/recombine model;
    8. simple coherent quantum interference model;
    9. decohered version of the same model;
    10. non-Markovian controlled process.

For each model, compute or approximate:

- residual continuation states;
- exact or approximate predictive equivalence;
- consequence distance;
- effective dimension;
- covering structure;
- support-sensitive volume;
- weighted volume where physically available;
- change across horizon.

This finite program can eliminate weak formulations before the theory is applied to gases, organisms, ecosystems, societies, or cosmology.
