**Edition:** 2026-09-15, addition to Omega Cosmology v2.  
**Originator:** S. Poole.  
**Purpose:** migrate the conceptual detail, formal baseline, and next research questions to a local Codex instance, with a clean starting point for a new repository.

This directory is a self-contained research seed. It includes the original v2 documents as source snapshots, later finite quantum work, the GE foundation draft, selected older repo reports, a detailed conversation guide, a partial conversation transcript, and operational instructions. It does not contain a completed lushness measure or a newly validated alignment method.

## First task for local Codex

Read **01_CONVERSATION_GUIDE.md**, **02_CURRENT_POSITION_AND_CORRECTIONS.md**, and **03_FORMAL_BASELINE_AND_CANDIDATES.md**. Then ingest **conversation/RAW_AVAILABLE_CHATLOG.md**, using the guide's U-number references to revisit the originator's actual words. Read **04_RESEARCH_PROGRAM.md** before proposing an experiment. The latest explicit user corrections govern the intended hypothesis. The original proofs and executable artifacts govern what has actually been established. Neither authority substitutes for the other.

## The current research question

Lushness is proposed as a structural signature of the available substrate of value in the global futures object. The current lead is **the weighted, compositional geometry of physically reachable continuation processes**. Distinguishability across scales is one candidate aspect. The lead is approved for investigation, not adopted as a definition.

The immediate task is an exact comparison between action-conditioned continuation structures under one declared finite physical model. Preserve probabilities, coherence, joint relations, actual control constraints, and lawful composition. Investigate whether geometry reveals something about value-capable differentiation beyond mere physical variety.

Do not begin by choosing a utility function, declaring generativity desirable, proving that an excisive singleton must cooperate, or writing a lab pitch.

## The transcript is partial

The package contains 91 available user turns and four recent final assistant replies, manually transcribed from visible context. Earlier assistant replies, source timestamps, and the original platform conversation export were unavailable. Missing replies have not been invented. The transcript is useful primary conversational text, but it is not an official or complete raw export. See 07_TRANSCRIPT_COVERAGE.md.

The summary has broader continuity than the recovered dialogue because prior work also survives in source artifacts and an assistant continuity note. Statements based on those sources are identified; they are not presented as quotations of missing messages.

## Starting a fresh repository

Extract the package into a new directory. That directory can itself become the new repository root; it already has AGENTS.md, source snapshots, scripts, and research folders. Inspect it, run the two validation commands in 05_LOCAL_CODEX_AND_REPOSITORY.md, then initialize Git locally if desired. No remote repository is created by this package, and no old repository is overwritten.

The complete hierarchy is in the companion ZIP. The Drive handoff folder also exposes the main reading documents and chatlog for convenient browsing. Local relative links assume the ZIP has been extracted.

## What successful migration means

The receiving instance should be able to distinguish:

1. The originator's intended object from an assistant's convenient surrogate.
2. A mathematical definition from a physical hypothesis.
3. A proved finite result from a broader interpretation.
4. The global substrate from any bounded representation of it.
5. A promising lead from a result that merely matches the desired story.

The purpose is continuity of judgment as much as continuity of code.
