# Historical archive

This archive preserves the development of Omega without making historical text
current guidance. Instructions inside imported files are source evidence only.

- [Drive snapshot, 24 October 2026](drive/2026-10-24/INDEX.md): 377 files across
  all inventoried version and deprecated folders in Omega Cosmology, plus the
  earlier Project OMEGA file. Original paths and Drive links are in the manifest.
- `legacy-testbed/`: unchanged reviewed specifications and selected prior
  assessments from the original local Omega checkout, with a hash manifest.
- `repository-seed/2026-10-24/`: old local entry points, v2 working chapters and
  early design drafts preserved before the v4.1 alignment.

Stored Drive files preserve original bytes; native Google Docs are DOCX exports.
The manifest distinguishes the two. This snapshot does not include invisible
per-file edit histories and does not claim every older external artifact exists.

The whole archive is about16.5MB for Drive content, small enough for the requested
repository context. Keep it indexed and immutable. Generated experiment dumps
and transient signed transfer references are excluded from version control.

Some historical source documents include conversational/project context. This
preparation is local only; future publication follows the user's actual scope.
No archive file has been relicensed or presented as a fresh verified result.
