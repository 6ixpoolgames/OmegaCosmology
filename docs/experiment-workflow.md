# Experiment workflow

Current design: the reviewed platform handoff under research/platform/.

Use one pipeline: specify physical law and query -> validate -> compile/audit ->
profile -> source/config snapshot -> execute -> analyze -> report -> retain.
Snapshots make exploratory choices reproducible. They do not require guessing
winners or treating a missed prediction as a failed theory.

Each execution states physical endowment/boundaries, conditioning, resolution,
horizon, quantity, comparison kind, candidate family and compute/storage limits.
Whole modeled field is the declared model, not an unmodeled universe.

Exact and sampled modes share native events. Report precision, estimator bias
limits and unsupported queries explicitly. A partial search cannot certify an
optimum. Monitors add no physical states unless their records are actually
part of the law.

The report gives mechanism; what lushness ranked; parameter relationship;
comparison kind; horizon; what was challenged; omitted physics; uncertainty;
and next physical question. Keep normative interpretation separate from numeric
predicates and preserve unfavorable comparisons.

Generated outputs belong in ignored runs/. Compact evidence, frozen inputs,
receipts and reconstruction instructions can be retained with a study. Pin
referenced artifacts. No automatic deletion, commit, push or upload follows a
run. Existing historical workflow files are archived as sources, not active gates.
