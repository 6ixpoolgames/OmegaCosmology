# Provenance and reference selection

On 24 October 2026 the author selected v4.1 as this repository's canonical starting
reference and requested retention of old versions and deprecated Drive files.

The [Drive snapshot](../archive/drive/2026-10-24/INDEX.md) inventories every file
listed in the Omega Cosmology and Project OMEGA trees during intake: 377 files
across 25 folders. The manifest records source IDs, original paths, MIME types,
timestamps, stored-source lengths, archived representations and SHA-256 hashes.
Stored files retain original bytes. The 44 native Google Docs are DOCX exports;
their hashes certify the exports, not inaccessible native storage bytes.

This is a snapshot of accessible files and separately named revisions, including
deprecated folders. It is not a claim to have exported every Drive per-file
edit-history revision. No Drive file was edited, moved or deleted.

The [v4.1 manifest](../sources/v4.1/MANIFEST.json) selects the active v4.1 folder
plus foundations r4 as the starting reference family. It records r19 availability,
the missing discussed r20, and the proposed/canonical outline distinction.
Working chapter copies start byte-identical; later edits do not rewrite sources.

The old local repository seed and v2 working chapters were archived before
the entry points were updated. Its [manifest](../archive/repository-seed/2026-10-24/MANIFEST.json)
preserves original bytes. Existing sources/manifest.json and P001 evidence remain
unchanged and are still checked by their historical reproduction commands.

Selected reviewed platform documents and prior physical assessments were copied
from the original Omega checkout into archive/legacy-testbed with hashes. One
evidence JSON is now explicitly marked as a redacted derivative: local Windows
account paths were replaced for publication, with original/published hashes
retained and the unredacted original kept only under ignored .local/. Active
specs adapt package paths and relative source links; [IMPORTS.json](../research/platform/specs/IMPORTS.json)
records that relationship. The old checkout and its runs were not moved.

Source ownership and notices remain attached; see NOTICE.md. Initial preparation
was local; subsequent publication was explicitly authorized after privacy review.
The existing remote's MIT LICENSE is retained without rewriting imported notices.
Raw transfer plans containing transient
signed download references stay in ignored .local/, not the archive manifest.
