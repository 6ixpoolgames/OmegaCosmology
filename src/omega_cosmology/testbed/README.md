# Finite classical test bed

The first engineering slice of the reviewed design is implemented here.

| Module | Responsibility |
|---|---|
| semantics | Six serializable records, conditioning, scope and comparison checks |
| physics | Rational energies, finite local rules, reversible event pairs and declared symmetries |
| models | R0 calibration and concrete R1/R2 grammar examples |
| backends | Complete reachable enumeration and shared-law Gillespie trajectories |
| history | Full histories, small projected word laws, support, refinement and irreducible asymptotics |
| thermodynamics | Source-off reference, work/heat ledgers and availability benchmark |
| conformance | Transparent finite mathematical reference cases |
| readouts | Passive coordinate shares, activity coordinates and ordered-event witnesses |
| monitors | Declarative path witnesses with explicit absorbing aborts |
| finite_study | Shared protocol-driven exact assay; R1 reproduction and R2 evaluation |
| analysis | Separate horizon/cadence profiles and directed metric-specific effects |
| structure | Native-route audits and legal-state rate probes with explicit limits |
| ecology | Functional persistence, loss/return and occupancy queries; no ancestry inferred |
| ancestry | Native marked assistance genealogy for distinct binary component slots |
| physical_modules | Versioned storage/damage repair and generic costed cycles sharing a resource |
| occupancy | Reversible finite catalytic contacts, shared ports, bound failure and opportunity costs |
| repair | Two-slot repair/access loop with explicit feedback conversion control |
| signals | Paid writing/resetting, energetic warning registers and physical escape/blocked response |
| readiness | Fractional reserve bills, brief openings, paid failure marks/cues and four fixed response circuits |
| registers | Composable bank/carrier payments for native reversible register reactions |
| readiness_v2 | Versioned fuel-powered cue/reset successor; old readiness physics stays unchanged |
| foreclosure | Native structural history-support loss with hidden-state subsets; finite-word suppression LP |
| projections | Known-root projected-history bounds retaining hidden-state memory |
| filtering | Paired full-past projection estimates, exact-mean controls and explicit statistical uncertainty |
| workflow | Windows process-tree caps used by the snapshot runner |

Install the testbed extra, then use scripts/run_testbed_calibration.py. The
engineering report and worked models are under research/platform/. This package
does not yet implement population ecology, generic graph matching, spatial
transport or an optimizer. A Gillespie path alone is not an entropy estimator. No
physical-faithfulness or ethical-correspondence claim follows from these tests.

See the [ecology analysis contract](../../../research/platform/specs/ECOLOGY_ANALYSIS_SPEC_r1.md).
Organization predicates and monitor labels are query-only. Ordered monitors
cannot certify connected ancestry; local coordinate entropy shares cannot stand
in for a subject's projected history entropy.
The separate ancestry adapter tracks constructed parents and children, resets
basal replacements to depth zero, preserves historical achievement after loss,
and rejects unsupported exchangeable or multiple-parent attributions.
The [coupled slice](../../../research/platform/specs/COUPLED_AUTOCATALYTIC_SLICE_SPEC_r1.md)
uses these modules; it does not change retained R1/R2-v1 laws. The projection
bound adapter reports interval width and rejects over-budget words and unsupported
conditioning. Its analytic inequalities are evaluated numerically, not with
rigorous interval arithmetic.

The [occupied assistance design](../../../research/platform/specs/OCCUPIED_ASSISTANCE_DESIGN_r1.md)
replaces instantaneous assistance only in its new adapter. Kernel and continuous
occupation reference workspaces are explicit per-protocol caps; existing kernel
defaults remain unchanged. The filtering estimator also reports a separately
typed empirical-Bernstein family interval under ideal iid/exact arithmetic;
this is not a rigorous floating-point entropy certificate.

The S3 assay supports explicit per-preparation energy declarations, retaining
the protocol-wide default. Matched fault roots and different-energy intact
diagnostics are labeled separately. Foreclosure queries use Boolean native
support; local observation histories are not made Markov. Functional profiles
also report native graph closure independently of recovery time. Memory reserve
checks now gate capped workers and aggregate finite-study dispatch.

## Paid warning and response companion

`signals.py` composes a repairable access world with energetic registers and
bank-powered response. Both kinetic writing and paid write/reset versions are
retained, with native reverses and no hidden event-label entropy. The exact
assay, samplers and projected-history bounds use the same LocalModel law.
See [S4b](../../../research/studies/S4b-paid-warning/README.md) for the functional
scope and unestablished suffering/record-faithfulness claims. No optimizer or
phenomenal-valence primitive is added.

`readiness_v2.py` uses `RegisterPayment` to charge register reactions to the
existing bank/carrier, with both refunds and source competition retained.
The [powered calibration](../../../research/platform/specs/POWERED_READINESS_CALIBRATION_r1.md)
checks register fidelity independently of history rankings. Circuit noise,
upkeep and fuel use remain physical parts of the modeled field; they are not
an entropy correction or a new valuation term.
