## Mechanism and scope

The old cue has strong closed-barrier reverse-reset activity and weak tracking;
reverse memory clearing writes most re-engage marks. A faster paired catalyst
alone cannot fix this. The successor uses the existing charged/spent carrier
as a physical input to cue writes/resets and memory clearing. No new carrier,
energy store, bath, source or free observer is introduced. The same source and
endowment feed both body and registers, so sensing competes with capture.

Reusable RegisterPayment records compose a representable bank debit and/or
consumption of one existing charged carrier into a normal reversible Rule.
Each reverse has exactly the corresponding heat uptake and input refunds.
The rate law is unchanged. Zero-bank sensing still consumes fuel, and is not
free. No direct external work is assigned to a register event.

The successor separately exposes cue write/reset payments, memory write/clear
bills, stored bit/mark energy, paired cue/clear/response conductances, cue
selectivity and passive relaxation/upkeep. Source and response ablations are
explicit mechanism controls. The inherited warning circuit is unchanged; this
does not certify its biological fidelity. No physical variable is calculated
from lushness or an analysis monitor.

preparations, as in the original world; the native source must recharge it.
Thus early cue latency includes the real fuel waiting time. Local event tests
also exercise a charged carrier with an empty bank. No initially full carrier
is silently supplied to improve the cue's short-deadline performance.

These seven cases are mechanism/preparation calibration diagnostics. No joint
