# Analysis for interacting autocatalytic organizations

25 October 2026. Active local engineering direction following the user's request
to fix the analysis machinery. Extends the [platform architecture](ARCHITECTURE_VISION_SPEC_r3.md).
It does not authorize a new scientific parameter campaign or publication.

## Intention

The reusable object is a physical ecology: organizations maintain or reconstruct
enabling relations, share and transform resources, occupy interacting niches,
and change one another's continuations. Competition, parasitism, symbiosis,
plurality and colonization are relationships to investigate in this ecology.
They are not new rewards, species tags that predetermine behavior, or separate
simulators. Physical configurations and the native law come first.

Lushness remains complete conditional history perplexity. All represented
randomness remains. Numerical profiles, physical consequences and interpretation
are separate. Whole means the whole modeled field; unresolved bath/source
histories are listed. Functional measures never replace the objective.

The analysis must explain what a configuration enables, how that capability
arose, how it is sustained, how it affects other configurations, and what the
complete continuation comparison reports. A larger scalar or a sequence of
events is not sufficient evidence for all of those statements.

## 1. The analysis objects

Use the existing six semantic records; these are nested analysis declarations,
not a second incompatible contract hierarchy.

| Object | Physical content | Important distinction |
|---|---|---|
| Organization query | Predicate on constituents, connections and functional states; observation scope and identity convention | Function, identity and valuerhood are different |
| Enabling relation | Source configuration, target event family, resource conditions, basal/substitute routes | Required support versus rate acceleration |
| Construction episode | Birth/assembly event, participating material, assistance and bills, loss/repair conditions | Initial stock versus paid construction |
| Resource/niche | Physical local stocks, source/bath prescription, interfaces, occupancy, transport | Offered resources versus accepted work |
| Interaction contrast | Common physical question, comparison kind, parties/collectives, matching and endpoint/profile quantities | Local benefit versus whole-field consequence |
| Evidence record | Native law/hash, query/hash, grain, horizon, numerical guarantee and claim level | Event order versus ancestry versus intervention |

An organization can span compartments and share components with another.
Membership may change over a history; a fixed coordinate owner is not a universal
identity criterion. A colony or coupled network can be queried at multiple
scales. Overlapping scopes cannot be added as independent totals.

Initial implementation supports declared functional predicates over fixed
coordinates and finite symmetry groups, plus marked assistance ancestry for
physically distinct binary component slots. Dynamic membership, exchangeable
genealogies and spatial colonies remain explicit adapter work, not claimed support.

## 2. Evidence levels and causal dependence

Report these separately, not as a single pass/fail ladder:

1. **Rule support:** the native law mentions an enabling configuration.
2. **Local rate dependence:** on valid paired states, the target rates differ.
   Include every relevant basal/substitute route. Invalid counterpart states
   are unmatched; they are never assigned zero rate.
3. **Ordered realization:** selected physical events occur in an order.
4. **Connected ancestry:** the constructed object at one stage actually serves
   as an enabler of a later construction, with intervening identity/loss tracked.
5. **Mechanism dependence:** a declared paired mechanism contrast changes the
   outcome, with all changed rules, costs and boundaries shown.
6. **Physical intervention:** a disturbance/choice is performed and paid for
   within the encompassing law from a common present.

A legal-state rate probe is not a paid removal intervention. A catalyst may
increase opportunity without being strictly necessary. Basal recovery is an
important substitute, not automatically a flaw. Temporal correlation and ordered
events do not prove that a particular catalyst or captured resource caused repair.

Existing sequence monitors must label their evidence as ordered sequences.
They cannot be renamed generative-depth witnesses. First-episode queries must
be accompanied by repeated-use or return measures when throughput is discussed.

### Connected ancestry implementation contract

- Mark construction and assistance from the native event ledger, distinguishing
  basal construction from assistance by an eligible existing physical object.
- Track a newly built enabler into the next construction. A->B->C->A as a graph
  is not sufficient: a history must use the newly built B and C.
- Give initial seeds explicit depth zero. Do not reset depth when a path fails,
  when a unit is replaced, or when a favorable episode is found.
- Specify whether repair preserves identity and whether reconstruction creates
  a descendant. Report both conventions if physical equivalence is unresolved.
- Distinguishable slots can support a tiny exact reference. Exchangeable units
  need an equivariant genealogy or bounds from uniquely attributable events.
  Arbitrary labels or selecting a convenient parent cannot add scored entropy.
- An unresolved catalyst identity remains unresolved. Report a lower/upper
  witness bound; do not invent an extra random parent choice.
- Query memory is passive. Its marginal must reproduce the original physical
  process. A label that physically changes future reactions belongs in the
  physical state and must be accounted for there.
- Count completed chains and their depth distribution separately from the
  probability of one chosen first episode. Ambiguous overlapping episodes
  require a declared counting convention; never double count by accident.

Acceptance examples: three unrelated births fail connected-depth-three;
one connected chain passes; replacing its parent breaks continuity; basal
construction does not acquire assisted ancestry; relabeling unmarked units
changes neither score nor genealogy bounds.

The implemented exact first adapter requires distinguishable binary presence
slots. Each selected assistance event must preserve a parent guarded present
and create a child guarded absent. Initial material has depth zero; other
unlisted births reset to zero. Loss ends the instance. Depth is capped only
for query memory: the final bin denotes depth >= cap, never a truncation of
physics. It reports probability of reaching depth, a live descendant at the
deadline, and expected assisted births per depth bin. Each birth is counted
once; these are not independent chain counts. Multiple-parent attribution,
unmarked identity and resource-packet provenance are rejected/deferred.

This certifies ancestry along declared native mechanism marks. It does not
certify catalytic necessity or the physical faithfulness of the construction
semantics. The calibration worlds are numerical engineering references, not
costed ecological experiments or additional evidence for generativity.

## 3. Functional persistence and recovery

For every declared functional predicate and initial distribution report:

- initial and deadline functional probability;
- integrated functional time;
- probability of ever functioning by the deadline;
- probability that initially functioning paths never lose function;
- unconditional probability that initial function is lost and later returns;
- probability of return followed by function at the deadline;
- expected entries into and exits from the functional set.

Initially absent organizations cannot be counted as survivors or as recovering
their initial function. Report conditional recovery only beside the unconditional
mass and its denominator. Return does not prove paid repair, retained identity,
causal reconstruction or permanent foreclosure. Graph-based structural closure
and history-support foreclosure remain separate queries.

Knockouts, source interruptions and niche disruptions need their own physical
implementation and accounting. The profile queries work on their resulting
laws/presents, but the analysis must not silently perform costless interventions.

## 4. Physical opportunity and cost audit before interpretation

Inspect the actual native event set, not rule names:

- Does capture operate with the claimed enabling apparatus absent?
- Is a route accelerated or newly made possible? What substitutes remain?
- Does an upkeep payment preserve function, or merely dissipate energy?
- Can failure happen when the bank is empty, full or unable to accept refunds?
- Can a loaded structure spill, leak or dissipate on breakdown? If not, say so.
- Does a prebuilt preparation include only stored formation energy, or an actual
  paid construction history? Equal total energy does not equate the two.
- Are forward and reverse catalyst effects both represented? Are they changing
  event competition or uniformly rescaling the entire generator?
- Which energy is available to which route, and what enables access to it?

Detailed balance and first-law closure are necessary checks, not evidence that
missing pathways or maintenance assumptions are physically adequate. Native
thermal routes remain in every arm. Source-off still has a bath; equilibrium
fluctuations are not sustained net extraction from a single bath.

The R2 storage and maintenance findings are required regression examples for
this audit. No rule is changed retroactively in its retained evidence.

## 5. Interactions are metric- and context-specific

Produce directed effects from a named source organization/collective onto each
target, plus an independently computed whole-field comparison. Each effect
carries metric, units, horizon, grain, conditioning, comparison kind, evidence
and numerical interval/tolerance. Report unresolved signs as unresolved.

Keep separate effects on:

- resource access, accepted work and net transfer;
- construction/reconstruction and functional persistence;
- local projected history lushness;
- whole-modeled-field history lushness;
- spatial occupation, dispersal and establishment where actually modeled.

A party can lose function and gain history breadth. That disagreement must stay
visible. Coordinate chain-rule shares are order-dependent explanatory quantities,
not projected subject entropy. Projected histories may be non-Markov: use exact
word laws/bounds or a validated estimator, not the full-state Markov formula.
An effect record must distinguish conditioning on the full present from an own-
present law with declared hidden-root provenance.

Ecological shorthand is an interpretation over a particular set of measurements:

| Relationship | Needed physical comparison and evidence |
|---|---|
| Competition | Shared limiting resource/site; changing one participant's access reduces another's opportunities; costs and substitutes included |
| Parasitic dependence | Consumer gains through a host-provided route while a declared host consequence worsens; dependence and host effect tested separately |
| Symbiosis/mutual support | Coupled partners improve declared functional outcomes relative to physically matched alternatives; also report whole/local lushness |
| Plurality | Copies versus differentiated organizations under matched inventory/source opportunity; redundancy, complementarity and common-mode shocks |
| Colonization | Costed dispersal, arrival and establishment in explicit niches; source population and niche modification remain in the field |

Positive-negative lushness signs alone do not establish parasitism; positive-
positive signs alone do not establish symbiosis. Pair effects need not predict
the collective. For three or more parties report higher-order complementarity
using explicitly matched factorial contrasts when constructible, not additive
assumptions or a hidden uniform prior over organizations.

## 6. Niches and expansion

Represent resource types, gradients, occupation, transport and cross-niche
coupling physically. A niche name cannot grant free yields, exclude another
party by fiat, teleport material or rebuild memory. Dispersal costs and transit
state belong to the law. Abiotic niches may change through resource use, waste,
construction or damage. Common boundaries do not imply statistical cancellation.

Analysis queries can identify a functional configuration in each niche, its
arrival, its sustained establishment, and its effects on occupied neighbors.
First arrival, establishment and persistence require different queries. Interacting
niches and communities become compositional analysis objects; they are not extra
terms stapled onto lushness. Finite inventory/capacity and omitted transport are
reported before interpreting growth. No unbounded-compounding claim follows
from a bounded exact study.

## 7. Comparison design and profiles

The primary access comparison matches the offered physical gradient and material
opportunity. Accepting more work can be the access mechanism. Equal realized
throughput/activity are secondary diagnostic contrasts, with residuals and
changed source prescriptions explicit. Source-off is a boundary contrast, not
the disordered opponent of a driven organization.

Same-law unassembled preparations retain native self-assembly and every common
route. Do not hold them disordered. Mechanism ablations explain dependence;
they are not alternative choices from one present unless physically implemented.

Report two separate axes:

- **Cadence audit:** change observation interval at a fixed horizon and law.
- **Horizon profile:** extend the history at a fixed cadence and law.

Report all observed sign-change brackets, interval accumulation differences and
limiting rates only where their hypotheses hold. Do not report a grid bracket
as an exact crossing, or claim no intervening crossings. A limited readout grid
is not a parameter sweep. State the independently varied physical parameters,
the number of laws, roots, horizons and cadences separately.

## 8. Standard evidence/report package

Every important comparison answers:

1. What physical configuration and relation changed?
2. What can each party and the whole field now do, lose or rebuild?
3. Which resources pay for this; which basal/substitute routes remain?
4. What evidence supports dependency, ancestry, persistence and reconstruction?
5. What did lushness rank at each horizon and resolution?
6. Is the contrast a preparation, mechanism, boundary change or implemented choice?
7. Which conclusion is numerical, structural, causal or an ethical interpretation?

Keep immutable original scores/inputs and a versioned interpretation. Post-hoc
diagnostics are allowed and labelled; there is no requirement to guess winners.
Preserve source hashes and compact results. Full arrays/paths stay reconstructable
in capped caches. A changed report must not automatically rerun the experiment.

## 9. Delivery and remaining work

Implemented in this repair:

- `analysis.py`: separate cadence/horizon profiles and directed metric effects.
- `structure.py`: route availability and explicit legal-state rate probes.
- `ecology.py`: passive function/loss/return profiles with analytic checks.
- `ancestry.py`: exact native-marked assistance depth for distinct binary slots,
  with absorbing historical achievement and live-descendant readouts.
- optional `structural_analysis` integration in the common finite-study assay.
- ordered monitors explicitly refuse to certify causal ancestry.
- retained R2 audit and revised interpretation, without modifying its native law.

Next engineering gates before a broader autocatalytic-ecology study:

1. Repair the physical storage/maintenance assumptions in a versioned fixture;
   retain the original as an explicit sensitivity arm.
2. Apply the validated labelled ancestry query to costed construction in the
   repaired fixture. Generalize identity/symmetry only after a labelled reference
   check. The sequence monitor itself remains insufficient.
3. Add validated projected-subject bounds scalable to the intended horizons.
4. Add an interacting pair and shared finite resource/niche using the same law
   grammar. Validate dependence and each scope before choosing an ecological label.
5. Expand to plural collectives and interacting niches, with costed transport and
   explicit capacity scaling after measuring the exact backend's limits.

The generic functional queries handle reducible generators. The common complete
assay still assumes irreducibility for stationary readouts; absorbing ecology
requires its separate class/absorption implementation before being run through
that assay. Do not hide this behind an arbitrary stationary distribution.

This repair establishes analysis infrastructure and bounded marked ancestry.
It does not claim that exchangeable population genealogy, spatial ecology,
maintenance necessity, multi-agent optimization or ethical correspondence has
already been implemented or demonstrated.
