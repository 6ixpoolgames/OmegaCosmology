# S4 paid warning, futile response and intermittent escape

26 October 2026. the author's "Run it" authorizes implementation, a capped smoke and
the first chapter-18-facing batch. This is a conceptual replication using the
new platform, not an exact reproduction of historical C.13. No desired sign is
an engineering acceptance condition. No publication accompanies the run.

## Object and comparisons

One repairable body has a finite bank, working apparatus, location and a paid
physical warning register. A native hazard accelerates reversible apparatus
damage in the exposed location. Sheltered capture is faster. Paid movement can
reach it only when a physical barrier is open. At a closed barrier a response
dissipates reserve without moving. This is a functional aversive-response proxy,
not a model of experience or a proof that the formal T-and-D suffering
definition is instantiated. No state is assigned valence or ethical weight.

Four mechanisms in each environment:

- T0: exposure-linked paid writing, no signal-dependent response.
- TX: identical signal plus paid escape/blocked effort.
- R0: hazard-independent paid writing, no signal-dependent response.
- RX: R0 plus the same response mechanism as TX.

TX minus T0 tests the consequence of coupling an existing warning to action.
TX minus RX tests informative against independent actuation. T0 minus R0
tests registers without behavioural leverage. RX minus R0 supplies the
uninformed-action control. A difference is a mechanism contrast, not a free
rewiring choice an embodied agent has. Within each environment all arms have
the same coordinates, energies, material, bath/source settings and known root.
Only declared sensor/actuator couplings differ. Actual expenditure and event
counts remain outcomes, not assumed matches.

## Stipulated physics and parameter plan

bank (0..3 half-energy ticks), location (exposed/sheltered), hazard (0/1),

tick. Register upkeep dissipates one tick while on. All native reverse paths
remain, including refunds and thermal excitation. No repeated action labels
or hidden self-events create extra futures. Parallel same-destination channels
aggregate before history entropy is computed.

Four environments: permanently closed, reversible barrier toggling.005 or.05,

## Independent-register calibration

Before entropy comparisons, fit R0 write and relaxation conductances to T0's
expected register occupancy time and total physical register switch count at
T64, separately in each environment. Include both write/refund and native
relaxation/excitation channels in switch counts. Keep identical bit energy,
write bill and upkeep. Positive log-parameter least squares; residuals and all
attempts retained. No entropy or desired ranking enters the fit. RX reuses
R0's rates without refitting. Response changes occupancy, exposure and bills;
these are measured outcomes. Matching two moments is not matching path laws,
correlations, charging costs or every horizon. Independent *write rates* do not
guarantee statistically nontracking occupancy in a coupled energetic body.
