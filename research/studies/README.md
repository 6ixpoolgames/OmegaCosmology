# Scientific studies

Create one directory per stable study ID when an actual study is specified.
Keep its question, physical model/configuration, comparison, readouts, analysis,
compact evidence, interpretation and reconstruction instructions together.

Reference the reusable platform and formal quantity IDs; do not copy a private
simulator/entropy/report implementation into each study. Generated arrays,
trajectories and caches stay under ignored runs/<study>/<run-id>/.

Possible future families include access, compounding, plurality, scope/control,
harm/recovery, contextual compression and boundary expansion. No empty completed
studies or fabricated results are created in advance.

Completed in the new substrate: [R1 constructed access](R1-constructed-access/README.md),
with numerical results, separate interpretation and reconstructible evidence.

[R2 further capacity](R2-further-capacity/README.md) adds costed capacity,
construction-sham controls and ordered feedback readouts, with the same shared
physical/history instrument.

[E1 coupled autocatalysis](E1-coupled-autocatalysis/README.md) maps shared-resource
cycles and cross-assistance, with cost/supply/turnover factors, matched preparations,
projected local-history intervals and explicit horizon/cadence analysis. Its
scientific interpretation is separate from the numerical completion checks.
