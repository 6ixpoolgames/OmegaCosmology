# Formal arm

The [retained-unit and state-mapping contract](contracts/RETAINED_INVENTORY_AND_STATE_MAPPING_r1.md)
describes scoped inventory interpretations and injective common-alphabet maps
for mechanism contrasts with different allowed-state constraints. The new
qualified inputs preserve their native laws; this does not convert an old
descriptive inventory into a chemical closure result or waive matching checks.

The [finite-profile and ending-law contract](contracts/FINITE_PROFILE_ENDINGS_r1.md)
records the implemented ergodic-projector/Poisson identity, transient bounds
and independent versus state-dependent ending quantities. Synthetic references
cover reducible and periodic kernels and multiple crossings. Float64 checks
are not verified rounding bounds, and this addition does not claim conformance
to a newer Appendix A that has not reached the repository.

The [module-binding contract](contracts/MODULE_BINDINGS_r1.md) describes explicit
coordinate ports in the distinct-slot classical adapter. It is exercised by the
R2 construction/transduction smoke, not a claim of general graph composition or
physical faithfulness.

The available formal starting source is [Appendix A r19](../sources/v4.1/A_FORMAL_CORE_r19.md),
read with [foundations r4](../sources/v4.1/FOUNDATIONS_r4.md) and current user
clarifications. The supplied Opus review referred to r20; that version was not
found in the Drive intake. No r20 conformance is claimed.

Use contracts/ for explicit semantic definitions and verification/ for the map
between stable proposition IDs, proof status, examples and executable tests.
Chapter numbering is metadata; it is not a semantic identifier.

The [source check](../research/platform/specs/FORMAL_SOURCE_CHECK_r1.md) verifies
targeted r19 definitions, corrects reviewer mappings and separates certification
against a named refinement from physical faithfulness. Foreclosure concerns
history support, not merely endpoint reachability.

Current classical targets include complete conditional history entropy, whole
and projected histories, two present-conditioning modes, resolution relations,
comparison admissibility and reference cases. The quantum/infinite-field scope
is stated in each source; a CTMC test does not validate incompatible quantum
record families or a joint space-time limit.

No new proof assistant package or formal conformance implementation is introduced
by this repository preparation. Historical proofs and finite checks retain
their exact evidence type.

The [scheduled-continuation contract](contracts/SCHEDULED_CONTINUATION_r1.md)
extends finite classical engineering queries to externally prescribed barrier
phases. It keeps the complete operation history, hidden-state projection memory
and native energy ledger. Tiny exhaustive history checks validate this new path;
it does not establish physical-resolution faithfulness or a later Appendix A
revision's conformance.
